# Piagam Proyek (Project Charter)

## Bagian A: Informasi Proyek
1. **Judul Proyek:** Aplikasi Pencatat Sesi Pelatihan Shuttle Kampus
2. **Deskripsi:** Aplikasi ini dibuat untuk memudahkan mahasiswa dalam melihat jadwal shuttle kampus dan memesan kursi secara real-time.
3. **Fitur Utama:** Melihat daftar sesi, menambah sesi baru, menghapus sesi, dan pencarian rute.
4. **Teknologi:** FastAPI (Backend), Vue 3 + Vite (Frontend), Axios (HTTP Client).
5. **Anggota Tim:** Salsabila Tahira Yasmin (Individu).
